# Datathon 26 — ForteBank: контроль кассовой дисциплины по видео

AI-сервис, который находит на видеозаписях кассы визуальные признаки нарушений кассовой дисциплины
и показывает кадр-доказательство, таймкод и норму НБРК. Работает полностью локально.

- `service/` — FastAPI-сервис (API для жюри + веб-интерфейс)
- `analysis/` — разбор датасета, типы нарушений, нормативная база, разметка `labels.json`
- `scripts/` — служебные скрипты

## Датасет

Видео организатора не хранятся в git. Они лежат в приватном релизе `dataset-v1` этого репозитория:

```bash
scripts/fetch_dataset.sh   # нужен gh auth login с доступом к репо
```

Данные используются только в рамках хакатона. Если репозиторий станет публичным, релиз с датасетом нужно удалить до этого.
