# Datathon 26 — ForteBank: контроль кассовой дисциплины по видео

AI-сервис, который находит на видеозаписях кассы визуальные признаки нарушений кассовой дисциплины
и показывает кадр-доказательство, таймкод и норму НБРК. Работает полностью локально.

- `service/` — FastAPI-сервис (API для жюри + веб-интерфейс)
- `analysis/` — разбор датасета, типы нарушений, нормативная база
